# MATA 材质动画与固定调用组合

本阶段补齐结局辅助模型所需的材质动画依赖，尚未接入完整结局或所有背景实例。固定原版 EXE SHA-256 为 `a3c9360321d4e4687b1a8a095f514c6c38c327119d8f52aafe664f02bc51679e`；数值对照不代表日文原 EXE 或 Switch 实机画面对照。

## 原版语义与模块边界

完整加载器确认 MATA 位于模型 `+158`，加载入口 `419c86`，组采样 `4300e0`、轨道采样 `42f5f8`；`+160 / 4270e0` 属于 LIGA。此前 next 笔记中把后者列为 MATA 候选的推测已排除。

新增 `model/material_animation` 拥有轨道、关键帧和预分配提交数组。创建时复制材质初态作为零时刻键，再按原顺序插入磁盘键；相同时间（包括整数转 float 后重合的时间）覆盖已有键。磁盘 loop 保留完整非零值，不要求布尔。源模型释放不影响轨道数据；采样借用调用者持有的独立 `MaterialPose`，不涉及 Vulkan 或平台资源。

组时间缓存初值为零，相同时间不提交，包括期间由其他控制器编辑过的材质。少于两个键的轨道不提交。循环条件为时间达到末键且末键至少为 1，取 `trunc(time) % (trunc(last)+1)`；非循环越过末键时按末键到首键外推，不钳制到终点。精确命中键复制全部 17 个字段；插值使用原 float 权重与 double 中间运算，环境光固定 `(1,1,1,0)`。

原插值路径的 specular/emissive 第四分量来自未初始化栈，三个栈模式已观察到不同值；它们不进入当前光照公式。便携实现明确将这两个分量设为零，仅精确键保留文件值。因此这里的“误差零”只覆盖原版已定义字段，未初始化字段单列策略检查。缺失/歧义材质、负键时间和转换后达到 2^31 的时间明确拒绝，不复制原加载器失步或越界行为。

`material_pose_values` 按顺序提交完整材质数值，以索引和 ID 核对目标，并复用已有 alpha 范围规则；名称、ID、MATE 尾部 opaque 字段保持。整个值批次与 MATA 组时间在成功后提交，失败保持原状态。没有每帧堆分配。显式 restore 提交各轨道第一键（可能被磁盘零键替换），对应原析构恢复；destroy 自身不修改借用的材质实例。

## 验证

- 原加载、构造、插键、组/轨道采样、材质 setter 与析构指令实际执行。78 个真实模型和 60 个合成配置，共 15,360 次采样、374 条轨道、1,659 个归一化键、9,843,314 个已定义字段检查，最大误差 0；63,946 次未初始化 W 策略检查和 1,260 次原子拒绝检查独立记录。外部 hook 只处理内存、ID 查找和注册表脱离，不替代被测算法。
- 实际原 `4021a1` 的 ANIM/MATA/MORP 同帧组合：7 个辅助模型、840 帧（77 帧隐藏）、21,024 份矩阵、1,691,118 个顶点和 42,064 个已定义材质字段，最大误差 0。其他模型效果槽未装配，不称完整原模型分派。
- 普通与 ASan 实际资源遍历：78 模型、194 条真实轨道、9,360 帧、517,800 份材质，FNV 均为 `63d646cba531d7c8`。单元覆盖截断、5,000 个变异、重复键/目标、时间缓存、源数据独立持有、恢复及失败回滚；material-animation/material-pose 两项普通和 ASan 检查均通过。
- Vulkan 诊断使用 5 个辅助模型和 2 个背景模型的真实材质轨道，绘制合成平面。420 帧、80,640 个 RGB 通道与独立光照/混合公式一致，最大误差 0/255；观察到 165 次画面数值变化。重复时间不上传顶点，GPU 分配保持稳定；普通和 ASan FNV 均为 `d51b58261b830ce5`。这证明材质提交、上传缓存及渲染公式，未验证结局场景外观。
- 两项架构检查与指定 Mesa NVK Switch 构建通过，未定义符号 0；源码 NRO SHA-256 为 `d1df27ad7aaebbd12bbcc93702c8358391fe537588c2f621eeb9dead1849356b`。

原标题和雨雪交付包保持原哈希，没有用本阶段源码覆盖交付。完整 BOM 资源生命周期、GPU 蒙皮后的 BOM 回调、按秒模型效果组合和 flow16 仍待实现。特别是按秒入口给 MATA 的时间来自旧片段描述符的实际 source，不能用 ANIM 的 blend_from 代替；MORP 组混合入口 `433cbe` 也不能用普通采样伪装。Mac 防休眠继续。
