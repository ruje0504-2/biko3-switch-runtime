# 音量页控制、显示与试听组件（2026-10-01）

标题第三项 `flow0x30` 是“音量”，第六项 `flow0x60` 是“相册”；名称按日文实际 `op_08.tga` / `op_12.tga` 核对。此前 README 将其写成通用“设置”和“第六项”，已更正。本批只补齐音量页组件，应用入口和配置持久化仍待接入，不能据此称标题/暂停音量设置已可用。

## 实现

- `scene/volume_menu` 恢复 `4AB0C0`、`4AC224`、`4AC6A7` 的三条滑杆、按钮命中、键盘导航、拖动、试听、默认值及保存动作编号。图片尺寸和坐标按原缩放后截断成整数；每帧先捕获界面，再处理输入，保留原先重复绘制光标的次序。
- 音量分别为语音/BGM/效果音，滑杆范围 `-6000..0`，单位为 `0.01 dB`。默认按钮为 `(-1500,-2500,-2000)`。核心只返回保存动作，不自行修改原版文件或进程音量。
- `scene/volume_menu_render` 加载实际 `bk3_00` 图片，共享同名纹理，以原 ALPHA、无深度写入和半像素原点绘制快照。重绘不更新输入或音频。
- `scene/volume_menu_audio` 加载实际六个 `bk3_02` 缓冲，独占调用者指定的六个空闲 mixer voice。停止保留位置，新试听从头播放；退出释放自己启动的 voice，构造失败不清理其他所有者的声音。

对照时修正了草稿的音效映射：恢复默认用原槽11，保存与隐藏项用槽10；效果音试听随机选择槽6或7，而原槽7没有加载缓冲，保持其空操作。隐藏项默认禁用鼠标命中，原键盘仍可到该项；当前核心保留这点，不自行扩展用途。

`501E12` 的第七个键盘字节在原包装函数中未初始化。核心允许测试显式提供它以对照 `4AC6A7` 的普通/快速步长，实际输入适配必须明确设为0，不能继承未初始化内存。

## 验证

终态成对记录见 [verification JSON](volume-menu-verification.json)。可复现命令：

```sh
local/venv/bin/python tests/check_volume_menu.py \
  '尾行3 [汉化]/去码汉化补丁/汉化/尾行3中文版.exe' local/game/MAINDIR/Data
```

- 普通/ASan 各21次真实原构造、6,282帧（含522边界帧）、87,948次绘制及45,376次服务调用；菜单控制、几何、服务顺序一致。原尺寸缩放 `4A0590`、命中、滑杆及 `43ED45` 顶点计算执行固定 EXE 指令；只替代资源创建、设备、DirectSound、随机与指针操作边界。
- 原 x87 扩展精度在整除附近可能截断到相邻音量单位，例如2000变1999；移植版采用 double，测得音量最大差1单位，即 `0.01 dB`。此项明确作为数值差异记录，不称全部状态误差0，也没有为音量滑杆引入80位浮点模拟。
- 普通/ASan 各600帧真实日文图片和试听，覆盖960×720与503×377逻辑视口、三类试听、拖动、键盘调整、默认与保存动作。2,692,173个采样通道最大差1/255，22次重复重绘像素及状态不变；PCM1,152,000标量，普通/ASan摘要一致。
- 缺图/缺音构造失败、占用 mixer 范围拒绝均检查；两个视口退出后 GPU 回基线、六个私有 voice 释放。音频采用离线推进，不能代替 Switch audout 实机检查。
- 29项 Python 检查、两项架构检查与指定 Mesa NVK 交叉构建通过。ELF 未解析符号0；新增符号在静态库，尚未被生产入口引用。NRO仍为 `d8873a4ea515ba90a14ad4b22b99327b0b2b25a32d05d2548c1834357e9f230e`，16,240,696字节。
