# 原版灯光注册与绘制分派

本快照恢复中文 EXE `0x4a4159 / 0x4a435a / 0x4a4438 / 0x4a4701` 的灯光命名、注册、环境光和分组提交。EXE SHA-256 为 `a3c9360321d4e4687b1a8a095f514c6c38c327119d8f52aafe664f02bc51679e`。

`game/lighting_pass` 输出有序环境光、灯光开关、对象、flush 与投射阴影命令，保留模式 0/1/2/10 的顺序。查找父名称中首个大写 B 后，才执行忽略大小写的 BK3_L 后缀比较。环境光初始化优先第一组；帧更新则取首个 rank1，之后才取 rank2，不能合并两种选择规则。模式2只处理最后32个对象槽。

`scene/lighting_assets` 从真实 LIGH/FRAM 构造注册表，并读取灯节点当前发布世界矩阵的位置。58个背景质量配置、381盏灯包括 m01_04 和 m05_01 的第二组灯；不再假定所有背景灯属于第一组。渲染器新增已有灯光描述符的帧外更新，保留相机和雾参数。一个帧内不同绘制组使用独立描述符，避免后一次更新覆盖前组灯光。
