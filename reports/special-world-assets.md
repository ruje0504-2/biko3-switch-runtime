## 所有权与时序

场景拥有 bk3_14 的 h01_55..h05_55 主体、XAN、普通三眼槽 FAM／MORP、bk3_01 外部脸部／眼纹理、主体灯光和 bk3_04 双镜头轨道。原加载器只有一次主体加载调用；Back 是主体内部节点，不另造背景演员。五组 Back 分别为主体 frame287／149／211／493／277，镜头焦点独立为 A_kao／A_Kao／kubiX／mune／atama。Back getter 返回模型 frame 索引，焦点 getter 返回森林 node ID。

加载按主体选片0、脸部初始化、Back 查找、灯光、双轨道挂接与焦点绑定的已有 CPU 边界执行。森林先挂主体，再挂两个镜头；attach 刷新之后只推进第二轨道一次，不补做最终发布。完整原加载器位于这些 CPU 步骤之间的音频／视频／UI 副作用尚未组合。资源失败清理本 owner，借用的相机、随机状态、过渡状态和事件 latch 不提交失败结果。

逐帧适配执行真实镜头、当前活动片段查询、源 tick 事件 latch、共享 CRT 随机数、401B0A 固定10 tick 请求、4026FE 主体推进、眼球朝向、眼纹理切换及口型／眨眼 MORP。镜头在主体推进之前执行；OPEN 保留读真实733700的规则，包括暂停时。面部内部时钟按原调用点逐次读取，重复相同表情请求不额外查询时钟。共享过程字段、包络、过渡、随机数及 latch 不复制成第二个进程所有者。后续服务失败保留已执行前缀。

`special_world_pass` 使用既有 flow48 的721B28／slot4灯光调度：group4为mode10，其他为mode1。此次组合真实灯光资产及既有 CPU 规则，但没有新增特殊剧情的完整 GPU 灯光或原版像素验收。

## Back 与普通隐藏的区别

原423B01递归写 frame+0x240，只禁止几何提交；原423A99写+0x70，会影响子树遍历。两者不能共用同一个隐藏标志。42273B在+240关闭几何时仍更新节点及后代的世界／父矩阵。

新增独立 draw-disabled 字段和按当前森林拓扑递归的设置接口，跨模型重挂也遵循实时拓扑。它不改局部矩阵、世界缓存、动画时钟或普通隐藏标志；后来挂入的节点保留自身状态。actor_render 的整模型与按访问节点批处理均捕获并检查该字段。已准备的 GPU 快照不随后续 CPU 开关改变；只有重新 prepare 才切换可见性。现有几何准备／上传策略保留，本次不声称消除了所有被禁止绘制对象的 CPU 准备开销。
