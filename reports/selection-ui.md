# 角色选择界面（flow38）

本快照恢复 `502480` 的图片构造、`504335` 绘制、`504802` 的输入/显示控制与 `506629` 导航。实际角色、脸部、相机焦点、灯光、语音的替换段 `505b87..50638e` 仍是必须成功的资源服务；目前只有 UI/音频夹具使用它，不代表 flow38 已接应用。

原指令依据仍为固定中文 EXE（SHA-256 `a3c9360321d4e4687b1a8a095f514c6c38c327119d8f52aafe664f02bc51679e`）。图片和声音来自未修改日文 PP。没有日文受保护 EXE 的指令对照或 Windows 完整截图证据。

- 零售构造加载槽1..41；试玩仅23..26、41、47。跳过的槽及导航、悬停、选中角色等状态保留。首次进程的 reveal 为0；构造没有擅自设为收缩终值。
- 绘制使用旧悬停状态，随后取绝对鼠标、绘制共享光标、取相对运动、处理光标计时、绘制标题和黑幕。控制在整个绘制阶段之后；键盘 warp 不回写本次传感样本。每帧只推进实际提交的图片。
- 五个文字标签按原浮点步骤趋近1或 `.55/.4/.3/.4/.55`；宽度和 UV 同时裁切，不能只缩放整张纹理。资料、语音、镜头和开始/返回按钮保留原独立判断顺序。取消声为系统槽2，选角/镜头/资料为槽4。
- 语音重播使用46435e从头播放；切角色的 Stop 保留游标。voice_active 可跨替换保留，并在下一次状态查询清除；缺少语音资源的重播明确失败。选角相同仍发确认声，但不替换资源。
- 选择页音乐变化为 `trunc(float(800 * 秒数))`、最小1，区别于标题400。开始先复制所选组照片数并写 group/area，再51c47e调度到8；试玩先调度2再写(0,2)。返回1/mode0。完成黑幕才复位选择/镜头。
- GPU 接口接收已经求值的顶点/UV/alpha，零 tick 重绘不改变状态；释放服务后保留本帧图像所有者直到提交结束。资源失败或回调失败终止在已执行前缀，不声称整帧事务。
