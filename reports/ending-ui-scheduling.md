## 无图片槽位

`ui/effect_sprite` 增加 enter/exit 模式 0 和显式 detached 更新入口。原函数先更新状态，最后才检查图片句柄决定是否绘制；从未加载和已经释放图片的槽位都不能直接跳过。模式 0 的半尺寸计算不意味着缩放清零；冷启动、再次进入和退出保留各自原来的顺序。

CPU 角度和最后提交的图形角度保持独立。无图片时仍更新摆动、方向、缩放和淡入淡出，保留图形角度缓存，不生成假图片或绘制项。重新构造图片按原构造器重置图形状态。

原版部分模式 0 和 idle3/5 分支会把空句柄交给 alpha/rotation 图形函数。本次先在原代码上验证四次实际非法读取，再仅拦截这些空图形写入进行比较；移植版继续推进 CPU 状态并省略非法设备访问。这是明确的兼容处理，不将这些样本称为未修改原程序的正常执行等价。

`scene/ending_stage_ui` 的统一分派覆盖 75 个槽位，保持共享 cursor8 的同一实例。已加载槽位必须有真实图片身份；未加载槽位不读纹理坐标，不消耗绘制容量。绘制数组已满时可以推进无图片槽位，但已加载槽位在推进前失败。错误的资源身份不能被当作空图片处理。

## 指示线及命中

`scene/ending_ui_geometry` 修改真实 line63，保留动画、计时和 pivot，接收调用者选择的整数锚点。两处原调用分别持有自己的 UV 滚动量；固定长度调用传入 `float(400 * scale)`，另一处传实际长度。

保留整数转 float、平方和舍入、未提前舍入的 sqrt 返回值、参考轴与 acos 象限偏移。重合点和轴向方向遵循原结果，不能用 atan2 替换。UV 末端由未提前舍入的除法结果加旧滚动量计算；当前绘制使用旧滚动量，之后推进并在 `>= .999f` 时写 `.001f`，不是取模。

圆形命中严格比较 `radius > distance`；边界属于未命中，未命中保留调用者原 distance。非有限或溢出计算明确失败并保留输出。指示线需要真实已加载资源、正宽度及非负有限长度/时间；这些输入校验是可移植接口边界，不模拟原程序无效参数访问。

## 公共工具栏

`scene/ending_ui_toolbar` 恢复指针捕获之后、分支提示之前的完整公共段。直接借用已有 frame/control/auxiliary 和 open 状态，使用真实 hover 与 sprite 更新，不增加替代状态副本。

- 手动镜头、phase8、phase9、过渡门限分别遵循原条件。
- 相机模式、辅助模式、悬停叠层、开关和暂停标记按原顺序选择；非常规整数不被擅自归一化。
- 相同按钮在一帧内可能推进、绘制两次，分别保留不可变快照。不得按槽位去重。
- 暂停项 60/62 必须先请求显示，只有匹配悬停时才推进和绘制。
- 按键服务可以改变实时模式；后续选择读取更新后的状态。
- 子操作失败保留已执行前缀并终止，不能声称整个公共段是原子事务。

本接口不包含主函数首次标记初始化、指针采集、分支提示、指针图标、黑幕、重载及末尾操作。缺失部分不提供返回成功的占位实现。
