# BOM 实际绑定与辅助模型生命周期

新增 `scene/bom_assets`，将已恢复的节点对齐、VIX 最近顶点映射及固定调用动画组合成原 `4a4dc3` 的 CPU 初始化流程。它借用外层实际选出的两个人物实例和全局 forest，拥有选择数据、映射以及辅助模型的材质/MATA/MORP 实例。BOM 内的模型文件名仍仅是元数据，不参与生产入口选择。

初始化顺序为五组节点查找、对辅助 child 清平移并按主模型 parent 对齐、全局 `423be2` 刷新、`4aaa40/4aab5e` 注册和建立映射、辅助 `40168c(0)` 请求、`4021a1` 固定更新、隐藏辅助根及子树。固定更新会推进 ANIM、MATA、MORP，但不发布新的世界矩阵。隐藏后再次固定更新保持时钟与三个动画组件；显式 forest refresh 仍忽略隐藏并发布缓存，与原版一致。

节点查找保留 `425904` 的深度优先顺序、文件顺序兄弟及首个空格后的名字匹配。特别是空字符串仍参与查找，会命中第一个未命名节点；不能把所有空 auxiliary 字段直接改成 NULL，也不能用全模型唯一名称检查替代。未命中的可选节点和网格保留 NULL；缺失必需 parent/child、无法支持的根 child 或歧义网格明确拒绝。

VIX 从显式选择资源包加载，以 uint16 LE 读取并忽略奇数尾字节。原打包尺寸函数 `4655aa` 在查找失败时返回零，散文件 `4a71de` 在打开失败时也返回零；`4a4dc3` 保留零计数后继续。因此真实 `kahansin.bom` 中缺少的 `mata.vix` 现按原零选择处理，`matafuku.vix` 正常绑定。资源损坏或读取错误仍失败，不能当作缺失文件吞掉。文件预检失败不改变借用的姿态；后续数学或映射失败会保留已经执行的前缀，要求外层终止这次场景加载。

初始化映射读取两模型的基础网格和刷新后的 mesh parent 缓存，先于辅助首步动画。该接口供新加载实例使用，不把已经变形的其他实例当成基础数据。模型名只在构造时使用；资源包可以在构造后卸载，映射、VIX 和动画键由实例独立持有。`bom_deform_plan / bom_assets_plan` 提供只读、有生命周期约束的源/目标网格及 VIX，与已有 source 映射共同供后续 GPU 提交使用，无需整网格读回。

## 验证结果

- 原 EXE 固定 SHA-256：`a3c9360321d4e4687b1a8a095f514c6c38c327119d8f52aafe664f02bc51679e`。`tests/original_bom_assets_oracle.py` 执行完整 `4a4dc3`、节点查找/位置/朝向、原 D3DX 全局刷新、网格注册/最近映射，以及 `40168c/4021a1` 的 ANIM/MATA/MORP 和递归隐藏。外部边界仅替代文件、堆、引用计数与矩阵栈生命周期。
- 七套真实 BOM/模型（两类资源读取分支）及 420 帧后续更新：539,490 份矩阵、810,810 个顶点、6,241 个映射、21,140 个已定义材质字段，最大归一化误差 0。真实缺失 VIX 零计数通过。材质插值的两个未初始化 W 分量沿用已记录的便携零策略，不纳入原版已定义字段等价声明。
- 普通/ASan 实际资源探针均通过七套、1,680 帧、2,779,920 个顶点、6,241 个映射，FNV `ac2010275e22b6d2` 一致；22 次预检失败保持原姿态。包括损坏资源不能降级为空选择、隐藏暂停、全局刷新、构造/销毁及从原 VIX 字节逐项核对 GPU 所需的只读计划。
- 五项相关 CTest 普通/ASan、两项架构检查通过；新增只读计划访问器的边界与复制所有权单元普通/ASan通过。指定 Mesa NVK 交叉构建未定义符号 0，NRO 仍为 `d1df27ad7aaebbd12bbcc93702c8358391fe537588c2f621eeb9dead1849356b`，因为应用尚未引用新结局装配器。

这些验证覆盖新加载的两模型注册范围和 CPU 初始化，不覆盖完整结局 loader、替代入口 `4a52bc`、每帧 BOM 控制/物理、按秒效果分派或 GPU 蒙皮后的 BOM 回调。后者必须在 ENVL 输出之后、实际网格绘制之前执行；继续保留 GPU 蒙皮，不通过整网格读回或整演员 CPU 回退接入。未新增 Switch 实机验证，原标题/天气 ZIP 保持冻结，完整移植与防休眠继续。
