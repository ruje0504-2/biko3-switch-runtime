# 固定调用动画与整模型 MORP 采样

这是完整 BOM 装配的前置依赖，不代表结局场景或完整 `4021a1` 媒体分派已接通。原 `4a4dc3` 在节点对齐与映射后，对辅助模型执行 `40168c(0) → 4021a1 → 隐藏`；不能用现有按秒更新传入零时长来代替。

`model/clip` 保存 XAN 描述符的有符号调用间隔 `+68`、实例计数 `+6c`。新增入口按原版先自增、再有符号比较，达到间隔才推进一个时间轴 tick；保留 32 位计数回绕。它不吞掉首步、不推进过渡、不按源速率方向钳制；自动链式换片后仍提交旧描述符的源时间，且不追加按秒入口才有的 ended 标志。`40168c` 比较 active 而非 requested，空片段无操作。

两入口共享计数：原按秒入口 `4027cc` 即使接收零时长，也会清零调用计数。本次交叉对照发现并补齐此行为。已有按秒采样、过渡和世界缓存提交语义保持。

`model/playback` 复用原子 ANIM 提交路径，返回本次实际源时间，供上层调用 MORP 等组件。`world/actor_pose` 在根节点隐藏时跳过全部更新、保留输出 sample，明确返回 submitted=0；其余情况保持根 local，不发布 world/parent 缓存。时钟/ANIM 与 MORP 是分开的提交，未来场景在后续组件失败时必须终止该帧，不能宣称整体事务。

`model/morph_group` 恢复 `433a7d` 的普通整模型采样：拥有解码键、每个目标的顶点和预分配暂存；原模型释放后仍有效。组缓存初值0，相同源时间直接保持，即使启用掩码改变；任意非零掩码启用对应轨道，全零掩码仍提交组时间。轨道保留原单独循环。掩码维数、非法源时间和采样失败不提交顶点或组时间。现有解析器的唯一目标约束、64轨道批次上限保持，不声称支持未验证格式。
