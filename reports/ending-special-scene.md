# 结局特殊镜头的真实场景适配

本阶段将 `4d9898` 调度接到实际结局资源的场景树、相机缓存和材质实例。**完整结局 flow16 仍未接入应用，双视角 GPU 快照仍待实现**。用户确认的 Switch 雨天效果保持已验收范围，本报告没有新增实机结局验收。

原指令对照固定中文 EXE SHA-256：`a3c9360321d4e4687b1a8a095f514c6c38c327119d8f52aafe664f02bc51679e`。资产使用日文零售版，原始文件保持只读。

## 实现边界

- `scene/ending_special_scene` 借用已加载的 forest、相机和有序材质登记表，将两遍绘制之间的节点查找、显隐、相机位置/朝向/瞄准及材质恢复接到现有 CPU 实例。绘制和视口/深度清除仍要求调用方提供实际服务，缺少服务即失败。
- `world/actor_forest` 新增沿当前树的名字查找与整棵子树显隐，包含跨模型重新挂接的节点。名字保留原版去掉首个空格前缀、大小写敏感、空名和第一个深度优先命中的规则。全局/相机锚点没有资产名字，搜索到锚点明确拒绝。
- 相机锚点的 local、world、旧 parent-world 独立读写；提交不重算 world，校验旧父缓存没有失效。只同步 `camera.pose.world`，不改变控制器位置、预设矩阵、焦点、FOV 等独立状态。
- 原 `423e72/423f33` 根据相机的 local 路径计算视图，**不发布角色 world/parent-world**；新增独立视图预遍历，复用到原有 draw 路径。隐藏节点不会阻断该预遍历，脱离全局树的相机保留旧视图。
- 原 `425196` 的 mode0 瞄准先写世界矩阵，再乘旧父逆矩阵生成 local。保留常量 W；零方向/垂直方向按原数学产生退化矩阵，后续需要逆矩阵的视图操作仍会明确拒绝奇异输入。
- 材质按调用方提供的真实登记顺序查找首个同名实例。普通十组模型不含特殊组4所需名称，测试另外显式提供两个重名材质以对照原资源查找与 alpha 写入，不能据此声称其他结局 loader 已实现。

全部操作不分配帧内内存、不推进时间轴。失败保留已经执行的顺序前缀，调用方必须结束失败帧。

## 验证

`tests/original_ending_special_scene_oracle.py` 执行原版完整 `4d9898` 及真实相机、节点、材质函数；`4a4701` 的设备/灯光部分收窄为原版有序根遍历，实际执行 `42261a` 和原矩阵栈。视口/清除/场景边界仅记录，不模拟成实际 GPU 绘制。

- 4,000 组原瞄准数学；十组真实资源、240 组合帧、1,920 中间/终态快照、1,040 根遍历。
- 2,559,264 份矩阵与 2,049,792 个材质字段，合计 42,998,016 浮点字段最大误差 **0**；显隐与描述符一致。
- 组合快照 SHA-256：`e47053968a0291beaad9017f3e029b68a76c8acab6658c961049fded38334e86`。动画 local 是双方显式共享的组件输入，本对照不重新验证采样器或光栅化。
- `ending-special-scene-probe` 实际加载十组资源、1,200 帧、2,410 次绘制边界、6,000 次设备边界、5,230 次树遍历、30 次缺服务/登记错误/后续失败检查。普通与 ASan 同 hash `b38c6950c3480f7f`。
- 新增的跨模型查找/显隐、独立锚点、隐藏相机路径、脱离树、失效父缓存与非法输入检查，以及现有节点/调度检查：普通与 ASan 各 3 项通过。ASan 使用 `detect_leaks=0`，不声称泄漏扫描。
- 共用 forest 变更的已有常规 GPU 回归：320 帧、22,980 队列项、1,707,968 顶点、40 次纯重绘、40 次空绘制，普通/ASan 最大相对误差 `3.68802e-7`，分配稳定。
- 两项架构检查和指定 Mesa NVK Switch 交叉构建通过；未定义符号 0。源码 NRO：`9c58594b1f057d4653ac840432bced1657318395180510b3524f343dcae629ad`。已交付天气包与原标题选人包保持冻结。

详细哈希与验证记录见 `ending-special-scene-verification.json`。
